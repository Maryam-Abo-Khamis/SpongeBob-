# 🧽 SpongeBob Eyes Tracker

[🔗 Live Demo](https://maryam-abo-khamis.github.io/SpongeBob-/)

### 📌 Project Description
This project is an interactive SpongeBob 🧽 character whose eyes follow the movement of the mouse cursor across the screen.  
It is built using HTML, Sass, and JavaScript, and designed to be Responsive, ensuring smooth performance on desktops, tablets, and mobile devices.

### ✨ Features
- 👀 SpongeBob’s eyes follow the mouse cursor.
- 📱 Fully responsive design across all devices.
- 🎨 Fun and cartoon-inspired user interface.
- ⚡ Lightweight and fast with no external libraries.

### 🚀 How to Use
1. Open the project [here](https://maryam-abo-khamis.github.io/SpongeBob-/).
2. Move your mouse around and enjoy SpongeBob’s eyes following you
